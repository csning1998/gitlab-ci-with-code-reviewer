# Substrate

This dimension binds mechanisms to processes, images, network trust material, and credentials. Primary audience is operators and maintainers; consumers require only the credential table unless private image or component mirrors are in use.

Substrate is an orthogonal dimension whose underlying questions concern execution hosts and the credentials presented to jobs.
